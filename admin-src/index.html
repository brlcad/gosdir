Create your Google OAuth client
  1. Open Google Auth Platform and create or select a project.
  2. Under Branding, use GOSDIR Admin and your email for support and developer contact.
  3. Choose an External audience. Keep it in Testing and add your account as a test user.
  4. Use only the basic openid, email, profile identity scopes.
  5. Under Clients, create a Web application named GOSDIR Admin Web.
  6. Set its authorized JavaScript origin to https://gosdir.com. Leave redirect URIs empty: this integration uses a JavaScript callback.
  7. Copy the client ID below, then continue with your Google account.

If requested: homepage https://gosdir.com/, authorized domain gosdir.com, privacy policy https://gosdir.com/admin/privacy.

The client ID is public. This integration does not use a client secret. Your private enrollment link is consumed after your first successful Google sign-in.
