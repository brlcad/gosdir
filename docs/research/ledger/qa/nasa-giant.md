# Coordinator QA: GIANT

Decision: admit the NASA Goddard optical-navigation software suite. The individual review is recorded in `nasa-luna-005-07.jsonl`.

- Government provenance and product identity: NASA [TechPort project 93240](https://techport.nasa.gov/projects/93240) ties GIANT to a Goddard IRAD project and OSIRIS-REx navigation verification/validation; NASA's exact [GSC-19381-1 catalog record](https://software.nasa.gov/software/GSC-19381-1) identifies the current GIANT product.
- Public source and license scope: the [repository](https://github.com/nasa/giant) contains the Python suite, tests, install files, and tutorials. Its exact [LICENSE](https://github.com/nasa/giant/blob/master/LICENSE.md) grants Apache-2.0; [commit 8576b12](https://github.com/nasa/giant/commit/8576b12d8950c4d3bb73502eddba73b7600f819a) is the 2021 initial public release with source and grant. Dependencies remain separately licensed.
- Year: 2021 is the first public grant-bearing source release checked.
- Notability and current use: NASA's exact catalog record documents use through OSIRIS-REx proximity operations and ongoing development; the public project docs provide installation and tutorials. NASA also describes the project in this [mission technology article](https://www.nasa.gov/technology/goddard-tech/nasa-optical-navigation-tech-could-streamline-planetary-exploration/).

The record is scoped to GIANT itself and does not claim the complete OSIRIS-REx software stack.
