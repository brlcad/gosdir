# Coordinator QA — GanttProject

Review date: 2026-09-28

Decision: admit as a France-sponsored open-source software project, with narrow
historical attribution. GanttProject began as Alexandre Thomas's independent
student project in 2003; the record does not imply that the French state created
or currently stewards the whole product. The project's first-party history says
Actimage developers sponsored by ADAE contributed substantial code to version
2.0 in 2005. The French Senate report identifies ADAE as an interministerial
service attached to the Prime Minister. This is project-development sponsorship,
not mere government use or SILL recommendation.

Four checks:

- Government provenance: pass — [GanttProject's official history](https://www.ganttproject.biz/about)
  identifies the ADAE-sponsored contribution; the [Senate report](https://www.senat.fr/rap/r03-422/r03-42211.html)
  identifies ADAE's government status.
- Public source: pass — [official public repository](https://github.com/bardsoftware/ganttproject)
  contains the application and build instructions.
- Eligible license: pass — the [repository's first-party LICENSE](https://github.com/bardsoftware/ganttproject/blob/master/LICENSE)
  applies GPL version 3 or later to the application; this does not transfer
  license terms to separately licensed submodules or dependencies.
- Primary evidence: pass — the [official release page](https://github.com/bardsoftware/ganttproject/releases)
  lists GanttProject 3.4 Beta VI (15 September 2026), and the official history
  reports broad adoption and the product timeline.

Open-source year: **2003**. The official history says Thomas wrote the first
version in 2003 and registered the project on SourceForge on 29 January. The
[SourceForge archive](https://sourceforge.net/projects/ganttproject/files/OldFiles/)
lists GanttProject 1.7 source dated 17 February 2003. The contemporaneous
[GNU Directory entry](https://ftp2.de.freebsd.org/pub/gnu/www/www.gnu.org/directory/all/ganttproject.html)
identifies GPL-2.0-or-later and says the license was verified on 19 February
2003. Current first-party code is GPL-3.0-or-later; the catalog records that
current grant, while the historical 2003 grant supports the open-source year.
