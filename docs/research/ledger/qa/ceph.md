# Coordinator QA: Ceph

Decision: add the core ceph/ceph distributed-storage product, not the entire Ceph GitHub organization, and describe its mixed file-level license terms conservatively.

- Government provenance: Ceph's [official history](https://ceph.io/en/foundation/history/) describes its national-laboratory-funded research origin and public LGPL release. The UCSC Storage Systems Research Center's [Ceph/exascale project page](https://www.crss.ucsc.edu/proj/exscale.html) additionally lists DOE/NNSA and Lawrence Livermore, Los Alamos, and Sandia national laboratories among the project sponsors; a recent TLS failure there is treated as a link observation, not a product failure.
- Public source: the canonical core project is the public [ceph/ceph repository](https://github.com/ceph/ceph), not the assigned Ceph organization landing page. Sibling projects such as Rook and Ceph CSI are outside this product record.
- License and year: Ceph's [README](https://github.com/ceph/ceph/blob/main/README.md) says most code is under LGPL 2.1 or LGPL 3.0; [COPYING](https://github.com/ceph/ceph/blob/main/COPYING) records file-level GPL, BSD-style, and public-domain exceptions and separate CC BY-SA-3.0 documentation terms. The official [project history](https://ceph.io/en/foundation/history/) distinguishes the 2004 research start from the public release under LGPL in 2006; use 2006 as the first public licensed-source year.
- Primary use and freshness: a Pawsey Supercomputing Research Centre coauthored [production case study](https://ceph.io/en/news/blog/2024/pawsey-reef-s3-performance-part-1/) documents two Ceph production clusters (11 PB and 27 PB). Current stable releases and the official [Ceph documentation](https://docs.ceph.com/en/latest/) support Active status. A transient HTTP 500 from `ceph.io` during link review is not treated as product failure; the catalog now uses the current official docs URL.
