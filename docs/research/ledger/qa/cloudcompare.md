# Coordinator QA: CloudCompare

Decision: admit the CloudCompare application as a publicly funded French research-origin project, with the attribution carefully limited to the documented CIFRE thesis and not represented as government authorship.

- Government provenance: the official [CloudCompare manual](https://www.cloudcompare.org/doc/qCC/Documentation_CloudCompare_version_2_1.pdf) identifies development as part of a CIFRE thesis funded by EDF R&D and supervised at Telecom Paris. France's [Ministry CIFRE program page](https://www.enseignementsup-recherche.gouv.fr/fr/les-cifre-46510) states that the program is fully ministry-funded and that participating companies receive a subsidy to employ the doctoral researcher. Together these primary records establish a project-specific public funding link; the inference is that the named CloudCompare CIFRE thesis received the program's grant. EDF R&D is not cataloged as a government agency, and no claim of government authorship is made.
- Public source: the assigned [CloudCompare/CloudCompare repository](https://github.com/CloudCompare/CloudCompare) is public and contains the application, build instructions, and user-facing distribution links.
- Eligible license: the exact root [license notice](https://github.com/CloudCompare/CloudCompare/blob/master/license.txt) grants GNU GPL version 2 or later for CloudCompare. CCCoreLib is separately LGPL-licensed, and plugins/third-party components retain their own terms.
- Year: the official [project introduction](https://cloudcompare.org/doc/wiki/index.php/Introduction) says that the project began at EDF R&D in 2004 but entered the public domain under GPL around 2009. Use 2009 as the first defensible public licensed-source year, not the thesis start year.
- Primary product evidence: the official [user manual](https://www.cloudcompare.org/doc/qCC/Documentation_CloudCompare_version_2_1.pdf) documents the exact application and its operational use by EDF surveyors processing laser-scanned power-plant interiors, dams, and cooling towers. The current public repo supplies build/installation guidance; the active source project supports the Active status.

The CloudCompare manual is hosted by its own project site and was reachable through the site's documentation page; if the PDF host later blocks automated fetches, the official documentation index is https://www.cloudcompare.org/doc/. The record remains scoped to the point-cloud application, not the entire repository's separately licensed libraries.
