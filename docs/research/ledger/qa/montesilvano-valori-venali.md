# Coordinator QA: Valori Venali Aree Fabbricabili OMI

Decision: admit as the Comune's narrow municipal land-value calculator. Luna review: `govoss-luna-005.jsonl`.

- Government provenance: the official municipal [service page](https://www.comune.montesilvano.pe.it/Servizi/Stima-Valori-Venali-Aree-Fabbricabili-OMI) describes the exact calculator and links its production subdomain. The [live app](https://valorivenali.comune.montesilvano.pe.it/index.php) identifies the Comune and links the source repository from its footer; the repo's publiccode metadata names the Comune as developer and owner.
- Public source and license: the assigned [public repository](https://github.com/comune-di-montesilvano/valori-venali) exposes source and setup instructions. Its root [LICENSE](https://github.com/comune-di-montesilvano/valori-venali/blob/master/LICENSE) is EUPL-1.2.
- Year: the EUPL license was added by [commit 88499f9](https://github.com/comune-di-montesilvano/valori-venali/commit/88499f9), dated 2026-02-26; earlier code is not counted as open source.
- Primary evidence/notability: the municipal service page identifies the target users, OMI values, land inputs, output and tax-reference use, and its direct link reaches a working calculator. At coordinator recheck on 2026-09-28, the app rendered a current generated report and input form, and its footer linked the same GitHub project. The municipal page also retains a contradictory “online service not currently available” message; this is documented rather than ignored. The functioning linked service and exact source link are stronger contemporaneous evidence than that stale status sentence.
- Agency/geography: Comune di Montesilvano, Pescara province, Abruzzo, Italy.

Product boundary: the project is the municipality's estimate calculator, not Agenzia delle Entrate's OMI data service or the municipal tax system as a whole.
