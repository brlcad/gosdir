# Project open source year audit

Reviewed 25 September 2026.

`openSourceYear` records the earliest year in which a project's source was publicly available under an OSI-approved license or a clear public-domain basis. It is not the project's founding year, service launch year, first production release, or later transfer to a foundation. An official project history is preferred. When no narrative release history was available, the audit uses the earliest licensed commit or release preserved by the canonical public repository.

## Interpretation notes

- OSCAL's public repository contained substantive schemas in 2016; its explicit repository license arrived later and its first tagged release was in 2019. The catalog uses 2016 because the field measures the first public source year.
- GOV.UK Frontend Alpha was public and MIT licensed in 2016; the combined GOV.UK Design System launched later.
- X-Road published its source in stages across 2015–2016, so the catalog uses the first publication year.
- Decidim's Barcelona stage and rewrite were developed openly in 2016; the independent project launch followed in 2017.
- Ghidra's public tool release and full source publication both occurred in 2019.
- GRASS 1.0 is documented as its first open distribution in 1985, before the term “open source” was coined.
